MUST READ RULES

💡 傻鸟服四大黄金法则

1. 御三家选择建议

开局选择御三家时，尽量避开丰缘三家（火稚鸡、草苗龟、水跃鱼）。因为进入剧情地图后你将能够直接免费领取一套丰缘御三家，把初始机会留给其他世代更划算！

2. 死亡不掉落设置

服务器开启了 KeepInventory（死亡不掉落），宝可梦也不会因濒死降低亲密度。请放心深入危险矿洞、熔岩区或挑战高难对战塔！

3. 剧情世界箱子必搜

拿到传送手册进入剧情世界后，每路过一个城镇或道馆都要仔细翻找箱子，每个小镇箱子送 手办 A x10 + 手办 B x10，前期 5 分钟就能攒出数张抽奖券！

4. 科技生活：Tom's 简易无线存储

服务器安装了 Tom's Simple Storage 模组。在基地安装存储终端与无线收发器，即可在一个界面管理所有箱子物资，打造整洁舒适的家园。

SEARCHABLE FAQ DATABASE

❓ 常见问题实时检索库

输入关键字（如：手办、御三家、雷达、指令、手机）即时过滤问题。

Q1: 为什么我在剧情世界领取御三家时宝可梦没了？ +
答：这是剧情地图自带脚本机制导致的。在剧情世界触发领取御三家事件时，系统会覆盖当前的队伍数据。
解决方式：在前往剧情世界前，务必输入 /poketoitem 将现有宝可梦转化为背包物品，确保身上槽位清空后再去领取剧情御三家。
Q2: 跨世界传输宝可梦具体怎么操作？会掉个体值/努力值吗？ +
答：绝对不会丢失任何数据！
1. 离开当前世界前输入 /poketoitem，宝可梦变成精灵球物品存入背包。
2. 传送至新世界后输入 /itemtopoke，即可原原本本释放出来。
包括等级、性格、个体值(IVs)、努力值(EVs)、配招、异色闪光全部完美保留。
Q3: 抽奖券怎么获得最快？ +
答：最快路径有三条：
1. 跑图开荒：去丰缘剧情世界的小镇开补给箱，每个箱子给 10x 手办A 和 10x 手办B。
2. 日常刷任务：每人 3 个专属任务，挑简单的做，不喜欢的随时按 200 秒冷却刷新。
3. 对战塔爬塔：3 BP 换 5 个自选手办，定向补齐紧缺的手办 A 或 B。
集齐 2 个手办 A + 2 个手办 B 到大厅村民处兑换 1 张抽奖券。
Q4: 为什么大转盘只放在出生大厅？玩家能带走吗？ +
答：转盘内容纯随机，为了保证全服公平，防止玩家拆下转盘无限放地上重置刷金色 OP 奖项，转盘被严格固定在出生大厅的 8 个指定展位，不可被破坏或带走。
Q5: 智能手机 (Smartphone) 值得优先兑换吗？ +
答：绝对物超所值，强烈建议作为第一追求目标！它集成了野外随时随地全队回血治疗、远程打开 PC 仓库、区域生成雷达等神级功能，能极大提升开荒与抓宠效率。
Q6: 狩猎公园 (CobbleSafari) 怎么玩？需要门票吗？ +
答：每日免费入场！公园内全天常驻 2 倍闪光概率加成，并且按水、火、草、电等属性严格划分生态区。天空中还会随机飘过热气球空投补给箱，是每天必去的抓宠胜地。
Q7: 怎么召唤神兽？神兽雷达在剧情世界能用吗？ +
答：通过抽奖获得或合成线制作出「传说雷达」后，右键雷达会共鸣指向神兽的栖息地坐标。到达坐标后右键召唤神兽降临。注意：请在生存资源区使用雷达，剧情世界因冒险模式和空气墙保护可能无法生成神兽祭坛。
Q8: 我开箱子会不会被其他玩家抢光？ +
答：完全不用担心！服务器安装了 Lootr 独立宝箱模组，世界里的每一个天然宝箱对于每个玩家都是独立可开的，人人都有属于自己的一份战利品。
Q9: 从剧情世界回主服后背包空了 / 变成幽灵 / 提示 "PLEASE CONNECT TO story"？ +
答：这是跨服数据同步机制的保护反应，数据不会丢，不用慌！
原因：在剧情世界异常退出（直接关游戏 / 断线 / 服务器重启）时，你的数据归属标记没有正常重置，主服会误以为「数据属于剧情世界」而拒绝加载，于是背包看着像空了，极端情况会变成幽灵（无敌但捡不了东西）。
解决：找群主/管理员说一声「跨服卡了」，管理员修正一下数据库标记就能恢复，背包和宝可梦原封不动。
避免：跨服切换时请走传送点 / 传送指令正常往返，不要直接关游戏。正常退出就不会触发。
Q10: 客户端报「5个本客户端未知的注册表项」进不去服务器？ +
答：说明你的客户端缺少服务器新增的模组。
服务器在原版 Cobbleverse 基础上额外加装了模组（命名空间 gaohaaddiotion 等），只装原版整合包就会出现这个报错。
解决：按群公告 / 安装教程页提示，更新到最新版整合包，或补装服务器新增的模组文件。

COMMUNITY FAQ

💬 社区问答（Reddit 高频 How-To）

整理自 r/cobblemon 社区 49 个高频问题——输入关键字即时过滤（会同时搜索上面新手百科的问题）。

找不到道馆怎么办？+
用训练师卡查看当前目标和要打的训练家；开局送第一个道馆（尼比）地图；失业村民+制图台可变地图向导村民交易道馆地图；屋顶颜色认路。第一个道馆必须是 Brock。
等级上限卡住不动了？+
默认上限 25 级，必须击败馆主/重要训练家逐步突破，每赢一场 +5~10 级，最终 100 级。
打败小刚但等级上限没涨？+
需要找 Trainer Association 特殊村民（所有村庄都会刷），对话选择你的系列 (Series) 后上限才会开始提升。
每个馆主的等级上限是多少？+
训练师卡会实时显示当前上限和进度；每场馆主/四天王战提升 5~10 级。
能不能跳过等级上限？+
开作弊可拿满徽章或直接用 /rctmod player set progress 命令推进（需服务器允许作弊）。
去新地区后等级上限会重置吗？+
会。地区进度绑定训练师卡，切到新地区上限按该地区进度重新计算。
馆主没生成/找不到道馆建筑？+
地区道馆只在未加载的新区块生成；可 /datapack enable 强制解锁或 /locate 定位。
馆主太难/太弱能改吗？+
馆主队伍基本硬编码。加难度可自己把上限设为与馆主最强宝可梦同级，或用 Radical Cobblemon Trainer 自定义队伍。
怎么快速升级？+
打高等级野怪（末地高等级未知图腾）、吃稀有糖果、或找朋友的高等级幸福蛋 (Blissey) 对刷。
Blaine/Giovanni 没刷出来？+
先确认地区已解锁且区块已加载；不行就 /function setup 或 /datapack enable 强制生成。
打完馆主没掉徽章？+
1.7.31 起徽章盒 (Badge Box) 只在馆主首次被击败时掉落，注意别漏捡。
训练师卡有什么用？+
显示当前等级上限、地区进度图、下一个要打的训练家，是核心进度工具。
拿了太多徽章会怎样？+
进度正常推进；若想跨区提前解锁，可用训练师卡重置或 /rctmod 调整系列。
道馆挑战有顺序要求吗？+
有。地区内按馆主顺序推进，击败当前目标后训练师卡会提示下一位。
末地 Boss 是什么？+
不是末影龙——是 100 级必闪裂空座 (Shiny Lv100 Rayquaza)！第一次进末地必定刷新。
进末地没看到裂空座？+
多人同进可能触发 bug。退出末地执行 /advancement revoke @a only minecraft:story/enter_the_end 再进，或用 /function Cobbleverse:spawn_rayquaza。
裂空座被打死/跑掉后还能再刷吗？+
删掉 enter_the_end 成就重新进末地即可再次刷新。
怎么抓 100 级闪光裂空座？+
备好大师球或大量高级球+催眠/麻痹状态，抓失败可重进重刷。
不想让末地刷闪光裂空座？+
Lumyverse 官方有禁用教程：lumyverse.com/en/cobbleverse/how-to-disable-rayquaza-in-the-end/
裂空座怎么 Mega 进化？+
给它学画龙点睛 (Dragon Ascent) 后，宝可梦菜单会出现 Mega 进化按钮。
Eternatus（无极汰那）在哪？+
末地 End Barrens 生物群系的地下固体方块上，70~75 级，超稀有生成。
Eternatus Cocoon（无极汰那之茧）怎么找？+
集齐 500 伽勒尔粒子后去末地；用宝可梦雷达（需 Locator Chip）+ 末地制图台合成地图定位。
CurseForge 版 Eternatus 怎么刷？+
在 End Barrens 用端石搭 3 层 12x12 平台（每层间隔 10 格高）即可满足生成条件。
怎么让 Eternatus 永久极巨化？+
给它一个星之核 (Star Core) 道具就能永久保持 Eternamax 形态。
末地还有啥好东西？+
Locator Chip（宝可梦雷达材料）藏在试炼密室 (Trial Chambers) 的凶兆宝库 (Ominous Vaults) 里。
末影之眼还有用吗？+
有！进末地仍走原版流程：末影之眼找要塞、激活传送门进入。
最强传说宝可梦有哪些？+
Mega 裂空座、Zacian、Calyrex 双马合体、Urshifu、Miraidon、原始固拉多/盖欧卡、Xerneas、Chien-Pao、究极奈克洛兹玛等。
有必闪传说召唤道具吗？+
有！在 JEI 里搜 Shining / Shiny / Radiant 版召唤道具，可在对应结构召唤闪光传说。
怎么孵化宝可梦蛋？+
同蛋组、异性两只放牧场，雌性会生蛋——蛋出现在牧场方块背面的巢里。
蛋招式 (Egg Move) 怎么学？+
最方便是用 Cobblecuisine 的紫罗兰奶昔 (Deluxe Violet Shake)，一次给 2~3 个蛋招式；或用 Mirror Herb 在牧场复制。
TM 怎么获得？+
宝箱、道馆战掉落、TM Craft 合成（空白盘从铜到下界合金）、百货商店购买。
为什么 TM 教不了这个招式？+
蛋招式/星招式/导师招式不能靠 TM 学，蛋招式必须用奶昔或繁殖获得。
Mirror Herb 怎么用？+
把带目标招式的宝可梦和要学的宝可梦放同一牧场，给要学的带上 Mirror Herb，等几分钟即可复制。
怎么刷高 IV？+
繁殖：新蛋随机继承父母 IV，把高 IV 后代继续当父母繁殖，逐代提纯。
牧场里的蛋按钮是干嘛的？+
那是禁用繁殖的开关，开启后该牧场不再生蛋。
怎么改特性？+
能力胶囊改普通特性，能力补丁改隐藏特性。
繁殖生出来是谁？+
永远是雌性那一方的物种。
跨种繁殖能学专属招式？+
同蛋组跨种繁殖，后代可能遗传平时学不到的专属蛋招式。
TM Craft 空白盘怎么用？+
空白盘可复制队伍里另一只宝可梦的招式；招式越强所需空白盘等级越高。
怎么整理/删除招式？+
在宝可梦可回忆招式列表中整理腾位，回忆列表也在那里。
Cobbleverse 闪率是多少？+
约 1/2048（比现代游戏 1/4096 更高）；可在模组设置里搜 shiny 查看具体数值。
怎么刷闪最快？+
跑图/飞行触发新刷怪 + 香薰料理加成 + 繁殖；装 Cobblemon Spawn Notification 模组提示稀有刷怪。
有闪光化石吗？+
有，洞穴生物群系里的化石和普通宝可梦一样有闪率。
香薰怎么提升闪率？+
Cobblecuisine 的香薰类消耗品叠加提升刷怪闪率，PokéNav 上能看到加成百分比。
服务器怎么提示稀有刷怪？+
给客户端/服务端加 Cobblemon Spawn Notification 模组即可。
刷闪要一直跑吗？+
跑动/飞行刷新新区块；也可建矿车轨道 AFK 挂机刷。
PokéNav 显示什么？+
显示当前香薰/料理的闪率与刷怪加成，方便判断要不要补消耗品。
必闪裂空座算闪光吗？+
算！100 级必闪是 Cobbleverse 的福利，抓到的就是真·闪光裂空座。
怎么知道某宝可梦在哪刷？+
右键 PokéSnack 查看激活后的生成概率；Lumyverse 官网也有全宝可梦刷怪表。
